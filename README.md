### ✈️ [SmartTour](https://kumkumrathee12.github.io/SmartTour/) — AI-Powered Travel Planning Platform

> 🌐 **Live Demo**: [kumkumrathee12.github.io/SmartTour](https://kumkumrathee12.github.io/SmartTour/)

A full-featured intelligent travel planning platform built with **Vanilla JS**, **Node.js**, and **Leaflet.js**.

| Feature | Tech |
|---------|------|
| 🪄 4-Step AI Itinerary Planner | JavaScript ES6+ |
| 🗺️ Interactive Route Maps | Leaflet.js |
| 🔐 Auth (JWT + bcrypt) | Node.js + Express |
| 💾 Cloud & Local Persistence | JSON DB + LocalStorage |
| 🌙 Dark/Light Mode | Vanilla CSS |
| 📄 PDF Export & Share Links | Pure JS |
